About Me

Saya adalah lulusan S1 Teknik Informatika yang memiliki minat mendalam pada pengembangan sistem backend dan rekayasa perangkat lunak web. Selama masa studi dan pengerjaan berbagai proyek, saya berfokus pada perancangan arsitektur server-side, integrasi REST API, dan permodelan basis data relasional untuk memastikan sistem beroperasi secara efisien dan konsisten.

Dalam alur pengembangan, saya terbiasa menggunakan PHP dengan Laravel serta Python, didukung pengelolaan database MySQL dan PostgreSQL. Saya juga memanfaatkan Git untuk pengelolaan versi kode dan Docker untuk standardisasi lingkungan aplikasi. Saya menyenangi tantangan seputar perancangan skema relasi data, pengamanan endpoint autentikasi, serta pembangunan logika bisnis yang bersih dan mudah dipelihara.
